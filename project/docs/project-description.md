# What SecondRound does

SecondRound is for people who want to sell used items through a timed auction. A seller creates an account, adds a name, description and image URL, then chooses a starting price, a minimum raise and an end time. An item can be edited before it is attached to an auction.

Visitors can search auctions and watch bids without an account. A buyer signs in to bid and can see the auctions they bid on or won. The seller can check their listings and results under **My auctions**.

The first bid must reach the starting price. Each later bid must reach the current price plus the minimum raise. Prices are whole HUF, and sellers cannot bid on their own auctions. An auction that closes with zero bids is marked unsold.

## What is outside the project

The auction ends with a winner or an unsold item. Payment, shipping and chat are outside the project. Listings use an image URL, and a seller who wants to auction the same item again must create a new listing. The app is set up to run locally for the course.
